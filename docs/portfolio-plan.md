
# Portfolio Plan

**Course:** IS218  
**Project:** Career Research Website  
**Date:** November 14, 2026

## 1. Intended Audience

The main audience for this website is recruiters and hiring managers who are interested in technology, artificial intelligence, and business-related careers.

The website should help readers understand my career interests, see examples of my work, and learn about the skills I am developing through my Business and Information Systems education.

I want the website to be easy to navigate and understandable even for someone who is not familiar with my projects.

## 2. Design Directions Considered

I considered two different website designs.

### Option A: Dark Technical Design

This design uses a dark navy background, blue accents, clear sections, and simple cards.

It creates a modern technology-focused appearance. It also makes the website feel connected to software development, artificial intelligence, and data.

### Option B: Light Professional Design

This design would use a white background, neutral colors, and a more traditional business layout.

It would create a clean and professional appearance similar to a business report or consulting website.

## 3. Selected Design

I chose the dark technical design.

I selected this direction because the website focuses on technology, AI, and information systems. The dark background and blue accents create a consistent appearance while keeping the content organized.

The website uses navigation links, separate content sections, and cards to make information easier to find.

The main design goal is to make the website look professional without making it difficult to read.

## 4. Portfolio Project Stories

I selected three projects that demonstrate different skills related to my career interests.

### Project 1: Rock Paper Scissors

**Technology:** Python

This project involved creating a Rock Paper Scissors game using Python. I worked on the game logic and tested different possible outcomes.

The project also involved unit testing, integration testing, browser testing, and GitHub Actions.

**Skills demonstrated:**
- Python programming.
- Problem-solving and logical thinking.
- Software testing.
- Debugging.
- Git and GitHub collaboration.

**Career connection:**

This project relates to software implementation because it demonstrates how to develop, test, and improve a working application.

### Project 2: Object-Oriented Programming Calculator

**Technology:** Python and pytest

This project involved building a calculator using object-oriented programming. It included arithmetic operations, command handling, calculation history, and software design patterns.

I also created automated tests and achieved 100% test coverage.

**Skills demonstrated:**
- Object-oriented programming.
- Python programming.
- Software design.
- Automated testing.
- Understanding and organizing code.

**Career connection:**

This project helps demonstrate the programming and software development foundation needed for AI implementation and technical engineering roles.

### Project 3: J&J Chocolates Online Sales Analysis

**Technology:** Microsoft Excel and statistics

This project involved analyzing 50 online customer transactions for a chocolate business.

I examined customer spending, purchase activity, browsing time, payment methods, and pages viewed.

The analysis helped identify patterns in customer behavior and sales.

**Skills demonstrated:**
- Excel and spreadsheet analysis.
- Descriptive statistics.
- Data interpretation.
- Identifying patterns and relationships.
- Business decision-making.

**Career connection:**

This project relates to data analytics because it demonstrates how information can be organized and analyzed to help businesses understand customers and improve decisions.
